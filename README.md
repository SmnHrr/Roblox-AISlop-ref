# AI Slop Content Ecosystem: Mechanics, Utilities, & Architecture

This repository contains reference materials, mechanics, and design patterns for Roblox "AI slop" games. 

## Purpose
This repository is curated strictly as a **conceptual reference archive** rather than a traditional production-ready software implementation. It is designed to serve as structured context (a "knowledge base") that can be ingested directly by AI agents, autonomous coding tools, or researchers to study, analyze, and replicate automated short-form content pipelines. It provides blueprint, game loops, and UI patterns so an AI agent can understand, replicate, and generate similar Roblox experiences from scratch.
